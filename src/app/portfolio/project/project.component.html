PROJECT 01 / TECHNICAL CASE STUDY

Shoe Rack

A component-driven commerce interface.

A footwear storefront built with Angular, TypeScript, SCSS, GSAP, and Bootstrap 5. My work focuses on the relationship between product discovery, responsive layouts, and shopping cart interactions.

Product discovery

Client-side product search and multi-criteria filtering by category, price, and attributes.

UI architecture

Reusable Angular components, shared SCSS styles, and responsive layouts across screen sizes.

Application state

Reactive shopping cart handling and a connected checkout interaction flow.

Interaction design

GSAP transitions and considered loading behavior that support navigation through the catalog.
