Shoe Rack — Footwear E-Commerce Platform

Production footwear e-commerce application engineered with Angular, TypeScript, and SCSS. Deployed on Vercel Edge with automated CI/CD and optimized for fast sub-second client-side interaction.

// KEY CAPABILITIES & ENGINEERING

  • In-memory multi-attribute filtering engine with memoized price range and category calculations
  • Reactive shopping cart store utilizing RxJS BehaviorSubjects and local storage synchronization
  • Modular component tree with strict TypeScript contracts and zero third-party UI library bloat
  • Fluid micro-interactions and dialog transitions crafted with CSS keyframes and tokens
  • High-performance responsive layout across all device viewports from 320px to 4K
